# 输出格式

默认输出**禅道(ZenTao)标准导入格式**。先生成 Markdown 中间稿（便于评审），再按需转 Excel/CSV 或 XMind。

## 禅道字段定义

| 字段 | 说明 | 示例 |
|-----|------|------|
| 所属模块 | 用 `/` 分隔层级 | 用户管理/登录 |
| 用例标题 | 简洁描述测试点 | 验证用户名密码正确时登录成功 |
| 前置条件 | 执行前需满足的条件 | 用户已注册，处于登录页面 |
| 操作步骤 | 分步骤，每步一行 | 1. 输入用户名<br>2. 输入密码<br>3. 点击登录 |
| 预期结果 | 每步对应的预期 | 1. 输入框正常显示<br>2. 密码掩码显示<br>3. 登录成功跳转首页 |
| 优先级 | P0–P3（P0 最高） | P0 |
| 用例类型 | 功能/性能/安全/兼容等 | 功能测试 |
| 标签 | 用于筛选，逗号分隔 | 登录,冒烟,回归 |

**优先级建议**：核心主流程/冒烟 = P0；重要功能 = P1；一般功能/边界 = P2；次要/异常提示 = P3。

## Markdown 中间格式

用管道表格，列顺序与禅道字段一致，供 `generate_excel.py` 转换：

```markdown
| 所属模块 | 用例标题 | 前置条件 | 操作步骤 | 预期结果 | 优先级 | 用例类型 | 标签 |
|---|---|---|---|---|---|---|---|
| 用户管理/登录 | 用户名密码正确时登录成功 | 用户已注册，处于登录页 | 1. 输入正确用户名<br>2. 输入正确密码<br>3. 点击登录 | 1. 正常显示<br>2. 密码掩码<br>3. 跳转 /home | P0 | 功能测试 | 登录,冒烟 |
| 用户管理/登录 | 密码错误时提示错误 | 同上 | 1. 输入正确用户名<br>2. 输入错误密码<br>3. 点击登录 | 3. 提示"用户名或密码错误"，停留登录页 | P1 | 功能测试 | 登录,异常 |
```

多步骤用 `<br>` 分隔；操作步骤与预期结果的步骤序号应一一对应。

## 生成 Excel / CSV

用 `scripts/generate_excel.py` 把上面的 Markdown 表格转成禅道可导入文件：

```bash
# 转 CSV（仅需 Python 标准库，禅道支持 CSV 导入）
python scripts/generate_excel.py testcases.md testcases.csv

# 转 Excel（需要 openpyxl：pip install openpyxl）
python scripts/generate_excel.py testcases.md testcases.xlsx
```

脚本按扩展名选择输出格式：`.csv` 用标准库（UTF-8 BOM，Excel/禅道中文不乱码）；`.xlsx` 需 openpyxl，缺失时会提示安装或改用 `.csv`。

## XMind（思维导图）格式

用于评审阶段快速梳理测试点，用缩进表示层级，可直接粘贴进 XMind 的 Markdown 导入：

```markdown
# 用户管理
## 登录
### 正常
- 用户名密码正确 → 登录成功跳转首页
### 边界
- 密码长度为最小值/最大值
### 异常
- 密码错误 → 提示错误
- 连续错误 5 次 → 账号锁定【假设】需求未明确锁定阈值
```
